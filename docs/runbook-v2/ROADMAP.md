# 1. Purpose

This roadmap tracks the overall execution of Portfolio V2.

It defines the project's major versions, their current status, expected milestones, and overall progress while delegating detailed planning and execution to each version's runbook.

---

# 2. Project Versions

## Phase 1 — Portfolio V2.0

**Status:** In Progress

**Goal**

Deliver the first production-ready release of Portfolio V2.

This phase introduces the complete owner-only publishing platform together with the public portfolio experience defined in the project specification.

---

## Phase 2 — Portfolio V2.1

**Status:** Planned

**Goal**

Expand the engineering experience by introducing interactive technical exploration features such as Engineering Playground, architecture visualization, and advanced content discovery.

---

## Phase 3 — Portfolio V2.2

**Status:** Planned

**Goal**

Implement future enhancements intentionally deferred from Portfolio V2.0 and V2.1 based on future priorities and research.
