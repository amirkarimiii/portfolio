## Context

The Analytical Bookshelf feature was deferred from the 2.0 release, as documented in `docs/known-deviations/0001-analytical-bookshelf.md`.

As part of planning the Bookshelf data model, its canonical information will need to be incorporated into the project's canonical data guidelines.

## Decision

Adding the canonical information associated with the Analytical Bookshelf data model to `docs/guidelines/canonical-data-guidelines.md` is deferred to 2.0.1.

The canonical information should be added after the Bookshelf data model has been planned sufficiently to establish the information that needs to be represented.

## Trade-offs

* The canonical data guidelines do not yet include the canonical information associated with the Analytical Bookshelf.
* The guideline remains incomplete with respect to the deferred Bookshelf data model.
* Deferring the addition keeps the canonical documentation aligned with the actual data model rather than documenting an unsettled model prematurely.

## Risk

The primary risk is that the canonical data guidelines remain incomplete for the Analytical Bookshelf until its data model is established and the corresponding information is documented.

## Resolution

After the Analytical Bookshelf data model has been planned, add its canonical information to `docs/guidelines/canonical-data-guidelines.md` as part of the 2.0.1 work.
