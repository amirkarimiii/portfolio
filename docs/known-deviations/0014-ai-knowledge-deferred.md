# AI Knowledge Deferred

* **owner:** Amir Karimi
* **category:** Scope Cut
* **status:** deferred
* **issued in:** 2.0
* **target resolution:** 2.0.1
* **last update:** TBD
* **related:**

    * `docs/capability/ai-knowledge/`

## Context

The documentation under `docs/capability/ai-knowledge/` is part of the project's AI-oriented knowledge and capability documentation.

Completing and incorporating this documentation is outside the intended scope of the 2.0 release.

## Decision

All work associated with `docs/capability/ai-knowledge/` is deferred from 2.0 to 2.0.1.

The documentation is not required to be completed as part of the 2.0 release and will be addressed in 2.0.1.

## Trade-offs

* The AI knowledge documentation remains incomplete during 2.0.
* AI-oriented documentation and related knowledge are not fully represented in the 2.0 documentation set.
* The work can be completed as part of the 2.0.1 scope.

## Risk

The primary risk is reduced completeness of the project's AI-oriented documentation during 2.0.

## Resolution

Complete and incorporate the `docs/capability/ai-knowledge/` documentation as part of the 2.0.1 scope.
